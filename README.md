# ClinicAssist

An AI-built front-desk assistant for a fictional clinic (demo).
It answers FAQs, flags emergencies (call 000) and triages appointment requests as Urgent, Routine or Admin.

Built with Claude. Uses sample data only. Matching is rule-based; a production version would use Claude on Amazon Bedrock with RAG.

Live demo: https://vaishnavi2508.github.io/clinicassist/
